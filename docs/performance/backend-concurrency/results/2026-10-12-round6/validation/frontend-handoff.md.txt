## 真实边界与未覆盖

夹具是程序触发 DOM 回调 → 当前版本生产 submit/lifecycle/persistence/decision/Stop hooks → 原生 Electron preload/IPC → Core stdio → 真实临时磁盘 SQLite / loopback 合成模型。两个版本使用各自生产 Host/Renderer 源码和相同夹具/依赖。没有真实模型计费、真实用户数据库或外发。

它不是完整 AppShell/Markdown 渲染、硬件点击或满载 UI。双 requestAnimationFrame 仅表示 frame opportunity，不证明 compositor paint；Stop RPC 回执也不等于 durable terminal，后者单独等待检查。Host 总量包含固定的 81 次计时区间外校验读取（另有重开进程 1 次）；不得把它们全部归因产品 UI，也不得从本次串行 50 动作推断并发 UI p99/SLO 或物理磁盘写入收益。全局最终门禁还需结合 Core 长稳态、故障及租约结果。
