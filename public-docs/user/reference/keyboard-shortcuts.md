# 键盘操作

当前版本没有独立的全局快捷键设置页。以下是应用界面中已确认的局部键盘操作；系统菜单和文本编辑的复制、粘贴、撤销等仍遵循操作系统标准。

## 对话输入

| 按键              | 作用                                                  |
| ----------------- | ----------------------------------------------------- |
| `Enter`           | 发送当前消息                                          |
| `Shift` + `Enter` | 在消息中换行                                          |
| `Escape`          | 关闭已展开的权限或 Skill 选择面板；具体取决于当前焦点 |

在新任务输入框中使用中文等输入法时，确认候选词的 `Enter` 不会被当作发送。

编辑既有消息时，`Enter` 提交修改，`Shift` + `Enter` 换行。

## 对话框与抽屉

| 按键                    | 作用                                                       |
| ----------------------- | ---------------------------------------------------------- |
| `Escape`                | 关闭可取消的对话框、图片预览、搜索框或 Automation 详情抽屉 |
| `Tab` / `Shift` + `Tab` | 按界面顺序向前/向后移动焦点；部分确认框会把焦点限制在框内  |
| `Enter`                 | 在聚焦的确认输入中提交；审批仍以当前按钮和状态为准         |

正在提交或有未保存更改时，界面可能阻止直接关闭并要求确认。`Escape` 关闭审批对话框不等同于“拒绝”动作。

## 下拉框和列表

模型、设置、Automation 和 MCP 中的选择器通常支持：

| 按键               | 作用                     |
| ------------------ | ------------------------ |
| `↑` / `↓`          | 移动选项焦点             |
| `Enter` 或 `Space` | 打开选择器或选择当前项   |
| `Escape`           | 关闭选择器并返回触发按钮 |

模型选择器和设置中的标准选择器还支持 `Home` / `End` 跳到第一个或最后一个选项；Automation 的部分选择器只实现方向键导航，不应依赖 `Home` / `End`。

## PDF 预览

当工作区 PDF 预览区域拥有焦点，且没有按下 `Alt`、`Ctrl` 或 `Command` 时：

| 按键                        | 作用     |
| --------------------------- | -------- |
| `←` / `Page Up`             | 上一页   |
| `→` / `Page Down` / `Space` | 下一页   |
| `Home`                      | 第一页   |
| `End`                       | 最后一页 |

## 可调整面板

当面板分隔条拥有焦点时，可用 `←` / `→` 调整宽度，按住 `Shift` 使用更大步长；`Home` 和 `End` 跳到允许的最小或最大宽度。Automation 右侧详情抽屉的方向会根据它位于右侧进行相应处理。

## 待处理消息队列

当排队消息左侧的拖动手柄拥有焦点时，使用 `↑` / `↓` 可以调整消息顺序。任务运行中发送的新消息才会进入该队列。

## 图片预览

打开图片预览后：

- `+` 或 `=`：放大；
- `-` 或 `_`：缩小；
- `0`：恢复默认缩放；
- `Escape`：关闭预览。

快捷键可能随焦点和操作系统辅助功能不同而变化。如果按键没有效果，先用 `Tab` 把焦点移到对应控件。
