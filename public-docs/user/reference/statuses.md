# 状态说明

状态用于描述系统已经确认的阶段，不应只根据动画、模型文字或等待时间推断结果。

## 普通 Agent Run

| 状态     | 含义                                  | 你可以做什么                               |
| -------- | ------------------------------------- | ------------------------------------------ |
| 空闲     | 当前没有执行中的 Run                  | 发送新任务                                 |
| 已排队   | 已接受任务，等待执行容量              | 等待；不要重复发送同一任务                 |
| 运行中   | 模型或 Tool 正在工作                  | 观察活动，必要时补充引导或取消             |
| 等待审批 | 已保存待处理动作，等待你的决定        | 核对审批卡片后批准或拒绝                   |
| 等待回答 | 根 Agent 已保存必要问题，等待整批提交 | 完成回答或明确不回答，再提交；也可停止运行 |
| 已完成   | Run 已正常结算                        | 检查文件、测试和来源证据                   |
| 失败     | Run 未完成并提供错误                  | 根据错误缩小范围、修复配置或重试           |
| 已取消   | Run 收到取消并已结算                  | 检查可能已经发生的副作用                   |

“已完成”表示运行流程完成，不自动保证业务结果正确；最终仍需按验收条件检查。

## FileChange

文件修改卡可能显示准备中、等待审批、正在应用、已应用、冲突、失败、已拒绝、已取消或结果未知。冲突通常表示文件已在读取后变化，应重新读取再生成修改；结果未知表示提交边界无法确认，必须先检查磁盘内容，不能直接重试。

## 子 Agent

| 状态          | 含义                                     |
| ------------- | ---------------------------------------- |
| 待命          | 节点存在，当前没有活跃 Turn              |
| 已排队        | 已有后续任务，等待执行                   |
| 处理中        | 子 Agent 正在运行                        |
| 等待审批      | 子 Agent 的动作需要用户在根对话处理      |
| 已完成        | 最近一次 Turn 成功结束，节点仍可再次唤醒 |
| 失败          | 最近一次 Turn 失败                       |
| 已中断        | 最近一次任务被中断                       |
| 结果未知      | 外部副作用可能发生，但无法确认终态       |
| 已归档/已停用 | 节点生命周期不再活跃                     |

右侧栏“子智能体”把“排队、处理中、等待审批”归入进行中，其他最近终态归入已结束。子对话是只读观察面。

## Scheduled Automation Task

Task 有两组互相独立的信息：

- **已开启 / 已暂停**：控制未来计划是否继续；
- **正常 / 需要修复**：说明目标、模型、权限或计划是否仍有效。

暂停不会取消已开始的 Run，也不阻止“立即运行”。“需要修复”时打开详情，选择有效配置并保存；仅把需要关注项标记为已处理不会修复任务。

## Scheduled Automation Run

| 状态     | 含义                                           |
| -------- | ---------------------------------------------- |
| 已排队   | 已建立本次配置快照，等待准入                   |
| 正在启动 | 正在绑定目标并创建根 Agent Turn                |
| 正在运行 | 普通 Agent Loop 正在执行                       |
| 等待批准 | 后台动作需要用户决定                           |
| 已完成   | Run 正常结算；结果可能是有更新、无变化或未报告 |
| 运行失败 | 配置、模型、Tool 或执行过程失败                |
| 已取消   | Run 结束且未继续执行                           |

触发来源还会显示为“定时”“手动”或“恢复”。恢复表示应用重启后合并处理离线期间错过的计划点。

## MCP Server

常见连接状态：

- **已停用/已关闭**：不会提供可调用工具；
- **正在启动/正在连接**：本地进程或协议连接尚未完成；
- **正在发现工具**：正在读取并验证完整工具目录；
- **已就绪**：完整目录可用于路由；
- **等待重新连接**：发生临时错误并处于退避；
- **能力降级/需要处理**：目录或连接不完整，需要查看详情；
- **错误**：启动、协议或目录校验失败。

保存服务器配置不等于已授权启动；“需要启动授权”或“授权已失效”时必须重新核对精确配置。

## “结果未知”为什么特殊

失败通常表示系统确认动作没有成功完成；结果未知表示动作可能已经发出。对文件写入、MCP、浏览器提交或收费服务，先检查真实状态再重试，否则可能产生重复副作用。
