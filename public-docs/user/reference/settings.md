# 设置参考

从左下角本地资料入口打开“设置”。左侧搜索框可以按页面名称或分组筛选设置入口。

## 页面一览

| 页面           | 主要内容                                 | 重要说明                                         |
| -------------- | ---------------------------------------- | ------------------------------------------------ |
| 常规           | 语言、系统通知、权限模式、上下文用量显示 | 默认权限始终可用；完全与自定义模式可关闭         |
| 个人资料       | 本地头像、显示名称和 ID                  | 只用于本地界面资料                               |
| 外观           | 明暗模式、主题、Diff 预览、侧栏效果      | macOS 字体平滑只在支持的平台显示                 |
| 配置           | 模型、服务商、联网搜索、图片生成         | 包含 API 地址和凭据相关设置                      |
| 个性化         | 工作模式、回答语气、自定义指令           | 自定义指令影响此主机上的所有任务，需点击保存     |
| 用量与费用估算 | Token、请求、模型明细、估算费用          | 估算值不等于服务商账单，也不区分币种             |
| 技能           | 查看、启停、安装、更新和卸载 Skill       | 安装包需先预览再确认                             |
| 子智能体       | 管理 Agent 模板库及其适用项目            | 模板修改只影响未来创建的子 Agent                 |
| MCP 服务器     | 管理用户添加的本地 stdio MCP Server      | 保存、启动授权、启用与工具审批是不同动作         |
| 浏览器         | 链接打开位置、下载设置、历史与数据清理   | 手动下载询问不会中断 Agent 下载                  |
| 环境           | 添加或移除本地项目                       | 移除项目不删除源目录，但会删除关联的本地应用数据 |
| 已归档对话     | 筛选、恢复或永久删除归档对话             | 永久删除不可从应用内撤销                         |

## 常规：语言与通知

界面支持简体中文、繁体中文、美式英语、英式英语、韩语、日语、法语、意大利语和俄语。切换后会更新界面、启动页、Automation 计划摘要和系统通知语言；模型回复使用何种语言仍取决于任务与模型。

普通任务通知可设为“从不”“允许通知”“仅在必要时”或“自定义”；这些预设只控制普通任务的四类状态。提示音和任务内容预览是普通任务与 Automation 共用的全局设置，Automation 的通知触发条件则在每项任务中单独保存。详见[系统通知](../capabilities/notifications.md)。

## 常规：权限

### 默认

允许在工作区内读取和写入；命令和文件修改在关键位置要求审批，并保持受保护的命令安全策略。适合大多数任务。

### 完全权限

扩大到受支持的工作区外读取/写入，并自动批准命令和补丁，使用更宽的命令安全策略。仍有永远拒绝的操作和路径校验。选择该模式时界面会再次确认。

### 自定义

可以分别设置：

- 读取：仅工作区或所有受支持位置；
- 写入：禁止、仅工作区或所有受支持位置；
- 文件编辑：要求审批或自动批准；
- 命令：要求审批或自动批准；
- 内置执行：符合条件的 Bundled Skill/内置 Capability 要求审批或自动批准。

自定义模式仍使用受保护的命令安全上限，不等同于完全权限。写入设为禁止时，自动批准文件编辑也会不可用；内置执行自动批准不会替代其他读写、命令或网络条件。

当前对话在输入框中选择本次任务的权限模式。Automation 保存时会冻结解析后的权限；以后修改此页面不会自动改写已有任务。

## 配置：模型与 Provider

当前支持以下模型接入类型：

- 通用 OpenAI-compatible Chat；
- 通用 Anthropic-compatible Messages；
- DeepSeek V4 Chat。

全局 URL 和 API Token 为仍使用默认连接的模型提供配置；单个模型也可以使用自己的成对 URL/Token。模型条目可设置显示名称、上下文窗口、图像输入支持和每 1k Token 的本地估算价格。上下文窗口应按实际服务配置，错误值会影响容量判断。

启用模型后，它才会出现在对话、Automation 和子 Agent 模板的模型选择器中。删除或停用正在被其他配置引用的模型，可能使对应任务需要修复。

DeepSeek 设置还提供思考模式和推理强度；实际支持仍取决于所连接服务。

## 配置：联网搜索

联网搜索需要同时“允许”并填写 Tavily API Key。查询和目标 URL 会发送给 Tavily。Key 当前与模型配置一起保存在本机 SQLite 中，不是系统钥匙串。

## 配置：图片生成

当前图片生成使用一个内置的 Seedream 配置档，可填写 HTTPS endpoint、模型和 API Key，并设置能力、默认 `2K` 预设及水印。界面的“配置完整”不代表远端连通或密钥已经验证，首次实际生成才会暴露远端错误。

## 技能

Bundled Skill 随应用提供；Installed Skill 可以从 GitHub 或你授权的本地目录安装。安装流程会先解析候选、展示文件与兼容性问题，再提交确认。Workspace Skill 位于具体项目中，不在全局管理页安装。

Skill 的启用状态不授予文件、命令或网络权限。具体区别见[Skill 与 MCP](../learn/skills-and-mcp.md)。

## 子智能体

Agent 模板保存在工作区模板库中，可以在创建或编辑时分配给一个或多个项目，也可以先不分配。名称和指令必填，模型必须已启用；描述用于帮助父 Agent 判断模板职责。模板可以停用、编辑或删除，但已有子 Agent 继续使用创建时的快照。

## MCP

MCP 页面管理用户添加的本地 stdio Server，配置包含名称、可执行文件、参数、工作目录和工具调用策略。应用受管的浏览器自动化已移到独立的“浏览器”设置页。

初次建议使用“每次询问”。“允许自动执行工具”仍不跳过服务器身份、工具目录和风险检查；“禁止所有调用”是停止调用的明确开关。

## 浏览器

- **网页 URL 和链接打开位置**：选择系统默认浏览器或 Captain Who 内置浏览器。
- **下载位置**：使用系统默认下载目录，或通过原生选择器设定自定义目录。
- **手动下载前询问保存位置**：只影响用户点击产生的下载；Agent 下载直接进入配置目录。
- **浏览历史与下载历史**：支持搜索、定位和删除记录。
- **浏览数据**：按时间范围清除历史、Cookie/站点数据和缓存；下载历史只支持全部时间清除。

## 环境与数据删除

“添加项目”通过系统目录选择器授权一个工作区。移除项目会永久删除 Captain Who 中关联的项目配置、对话、消息和附件记录，但不会修改所选目录里的源文件。

“已归档对话”可按项目筛选并恢复。删除单条或全部归档对话是永久本地删除，请先确认是否需要保留历史和附件。

## 用量与费用估算

可以查看近 7 天、近 30 天或近一年的 Token 趋势，并按模型筛选。只有配置了有效价格的消息才能计入估算费用。清空统计只删除用量统计记录，不删除历史对话中已有的 Token 详情。
