# Office、PDF、表格、演示和图片

MyCopilot 可以读取多种附件，并通过内置 Skill 和受管工具创建或处理 Word、Excel、PowerPoint、PDF 和图片。不同格式的“读取”“编辑”“预览”和“保存”能力并不相同。

## 支持范围概览

| 类型             | 作为附件读取                    | 通过 Skill 创建/编辑 | Files 右侧栏预览                    |
| ---------------- | ------------------------------- | -------------------- | ----------------------------------- |
| DOCX             | 支持                            | Documents Skill      | 不支持                              |
| PPTX             | 支持                            | Presentations Skill  | 不支持                              |
| XLSX / CSV / TSV | 支持                            | Spreadsheets Skill   | Office 不预览；CSV/TSV 可按文本预览 |
| PDF              | 可添加；正文需由 PDF Skill 读取 | PDF Skill/受管流程   | 支持，最大约 32 MiB                 |
| 常见图片         | 视觉模型可读取                  | 图片生成或其他工具   | 支持                                |

旧版 `.doc` 仅在 macOS 上可以借助系统能力提取文本；旧版 `.ppt` 和 `.xls` 不支持，请先转换为 `.pptx` 和 `.xlsx`。扫描 PDF 是否可读取取决于是否有文本层；不要默认把图片型扫描件当作可搜索文字。

## 添加附件

1. 在任务输入框点击“+”。
2. 选择“文件”或“图片”；也可以把文件拖入或粘贴到输入框。
3. 核对附件卡片，再选择能够处理该内容的模型和 Skill。
4. 写清楚希望读取、修改还是生成新文件，以及输出路径和格式。

输入框选择的单个附件最大为 8 MiB。只有标记并实际支持图像输入的模型才能直接接收图片。Office 附件通常由相应 Tool 按路径读取；PDF 附件会先登记安全读取路径，再由 PDF Skill 处理。它们不会把整个二进制直接塞进模型上下文。

## 处理 Word 文档

选择内置“文档”Skill，然后说明：

- 输入文档或从零创建。
- 标题、章节和样式要求。
- 是否需要目录、表格、图片或页眉页脚。
- 输出文件名和保存位置。
- 是否需要渲染检查。

示例：

> 使用“文档”Skill，把附件中的会议记录整理成 `output/meeting-summary.docx`。保留事实，不补写未确认内容；生成后渲染检查标题、分页和表格是否正常。

新建和编辑依赖 Skill 提供的受管 Builder/Editor；底层 Office 工具主要用于检查、验证和渲染。写入输出仍按文件权限审批。

## 处理电子表格

选择“电子表格”Skill，并明确：

- 工作表、列名和数据来源。
- 公式、汇总、筛选或图表要求。
- 哪些值可以改，哪些必须保留。
- 输出为 XLSX、CSV 或 TSV。

示例：

> 使用“电子表格”Skill 读取附件，按部门汇总金额并新增“汇总”工作表。不要覆盖原文件，保存为 `output/report-reviewed.xlsx`，并检查公式结果。

对财务或关键业务数据，不要只看 Agent 摘要；应在 Excel 等原生应用中复核公式、日期、单位和舍入。

## 处理演示文稿

选择“演示文稿”Skill，提供受众、时长、页数、叙事顺序、视觉风格和必须出现的数据。生成后要求渲染并检查文本溢出、遮挡、图片比例和版式一致性。

示例：

> 使用“演示文稿”Skill，根据附件报告制作 8 页内部汇报。先给大纲，再生成 `output/monthly-review.pptx`；不要编造数字，最后渲染逐页检查。

## 处理 PDF

PDF 可以作为附件添加，但发送时不会自动提取正文。选择“PDF”Skill，并说明要搜索的主题、页码范围和输出格式；Agent 会按需提取文本或渲染页面检查。

受密码保护或损坏的 PDF 可能无法处理。纯扫描 PDF 通常没有可搜索文本，需要渲染相关页面并使用视觉能力检查；复杂版式提取也可能丢失阅读顺序，应核对原页面。

## 配置和使用图片生成

图片生成需要单独配置：

1. 打开“设置 → 配置 → 图片生成”。
2. 填写 HTTPS 图片生成 URL、API Key 和模型 ID。
3. 确认服务支持文生图；需要编辑已有图片时还要支持图生图。
4. 按需设置水印并保存，再打开“允许图片生成”。
5. 在任务中选择“图片生成”Skill，描述画面或附上要编辑的图片。

当前只有一个图片生成配置档和一个受支持的适配方式，默认尺寸预设为 2K，不支持任意宽高。界面显示“配置完整”不代表远端密钥和模型已经验证；首次真实请求才会发现服务端错误。

图片请求可能产生费用。超时或网络中断后，如果界面显示“结果待确认”或“图片保存状态待确认”，不要立即重试，先到服务商侧核对是否已生成和计费。

## 查看和保存产物

- Office 输出通常保存到经过批准的工作区或允许目录，并在聊天卡片中提供“在文件夹中打开”。
- 图片生成结果在聊天中显示预览，可放大或下载。
- PDF、图片等受管 Artifact 可能通过安全引用供当前对话继续使用。
- 浏览器下载属于短期 Browser Artifact，需要显式导出。

右侧栏 Files 不能渲染 DOCX、XLSX 或 PPTX。重要 Office 文件应在原生应用中打开复核。

## 安全与保留

- 输出路径和写入动作仍受当前权限与审批约束。
- Artifact 引用不是全局公开文件地址，只在获准的对话和运行范围内有效。
- 重要产物应显式保存到你管理的目录；当前没有统一跨设备同步或永久 Artifact 保留承诺。
- 生成内容可能存在事实、公式、排版和版权问题，发布前必须人工审核。

## 当前限制

- Office 新建/编辑依赖对应内置 Skill 和可用的受管运行组件。
- 通用受管 Artifact 主要支持 PNG、JPEG、WebP 和 PDF；DOCX/XLSX/PPTX 仍作为普通工作区文件输出。
- 图片生成一次最多处理一张结果，当前配置档和尺寸选择有限。
- 大文件、页数、图片尺寸、运行时间和输出数量都有安全上限。
