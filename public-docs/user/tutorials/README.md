# 实战教程

这里的教程不是功能清单，而是可以从头跟做的完整任务。第一次使用建议依次完成前两篇，再按需要选择后续内容。

## 推荐顺序

1. [理解一个现有项目](understand-a-project.md)：让 Agent 先建立可靠的项目地图。
2. [实现一个小功能](implement-a-feature.md)：经历分析、修改、测试和人工复核的完整闭环。
3. [联网调研并撰写报告](research-and-write.md)：练习来源核对与文件交付。
4. [使用多个 Agent 并行工作](use-multiple-agents.md)：把可独立的工作拆给子 Agent。
5. [连接本地 MCP Server](connect-an-mcp-server.md)：为 Agent 增加外部工具。
6. [创建一个 Workspace Skill](create-a-skill.md)：把稳定做法沉淀为可复用能力。
7. [创建一项定时自动化](create-an-automation.md)：让任务按计划重复运行。

## 跟做前的共同原则

- 先用小范围、可验证的任务熟悉流程，再扩大权限和工作量。
- 把“完成条件”和“不要做什么”写进任务，而不是只写一个主题。
- 审批窗口出现时，先核对路径、命令、来源和影响范围。
- Agent 的文字说明不是完成证据；文件、测试结果、来源链接和运行历史才是。
- 涉及重要数据时先准备版本控制或独立备份。

不知道该使用 Tool、Skill、MCP、Multi-Agent 还是 Automation？先读[选择合适的能力](../best-practices/choosing-capabilities.md)。
