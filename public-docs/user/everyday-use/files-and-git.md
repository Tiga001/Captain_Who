# 文件与 Git

MyCopilot 中有三种容易混淆的文件操作：右侧栏“文件”用于**只读查看**，Agent 文件工具用于**分析或修改**，右侧栏“审阅”用于**检查和管理版本库变更**。

## 添加项目文件夹

在新对话的项目选择器中选择“新建项目”，或进入“设置 → 环境 → 添加项目”，再使用系统文件夹选择器授权一个目录。

项目建立后：

- 默认权限把读写范围限制在当前项目。
- 右侧栏“文件”和“审阅”绑定这个项目。
- 右侧栏“终端”从项目目录启动。
- 项目内 `.agents/skills/` 中的合法 Skill 可以被发现。

## 用“文件”查看内容

1. 打开右侧栏，选择“新建面板 → 文件”。
2. 在目录树中展开文件夹，或输入名称筛选。
3. 点击文件打开预览；再次打开同一临时页可以将它固定为独立标签。
4. 通过“更多文件操作”切换换行、复制文件地址或在系统文件夹中显示。

当前预览支持：

- UTF-8 和常见 UTF-16 文本、源代码。
- Markdown 源代码和渲染预览。
- AVIF、BMP、GIF、JPEG、PNG、SVG、WebP 图片。
- 非加密 PDF 的分页预览。

关键限制：文本最多读取约 1 MiB、最多渲染 5,000 行；图片最多 12 MiB；PDF 最多 32 MiB。过大的内容会显示明确提示。符号链接可以出现在目录树中，但不能展开、预览或用来跳出项目边界。

Word、Excel 和 PowerPoint 文件不能在“文件”中预览。可以在外部应用中打开，或交给对应 [Office Skill](../capabilities/artifacts-and-office.md)。

## 让 Agent 读取或修改文件

在任务中直接描述目标和范围，例如：

> 阅读 `src/config`，说明配置的加载顺序。只读，不要修改。

或：

> 只修改 `README.md`，增加安装前置条件；保留现有结构，修改后给出摘要。

Agent 可以列出、搜索、读取和补丁修改文件。实际可访问范围由当前项目和权限决定；模型写出的路径本身不会获得权限。默认权限下，文件修改通常会先出现审批。

对于大文件或超长工具结果，Agent 可能只看到摘要、首尾片段或分页结果。需要精确结论时，让它说明读取范围和遗漏部分。

## 用“审阅”检查 Git 变更

“审阅”只在当前项目被识别为 Git 仓库时可用。打开“新建面板 → 审阅”，选择范围：

- **未暂存**：工作区相对暂存区的变化。
- **已暂存**：暂存区相对 HEAD 的变化。
- **上一轮**：最近一次 Agent 轮次前后记录的变化，只读。

面板支持统一/分栏差异、自动换行、文件搜索、展开差异以及按需加载完整文件。最多展示 500 个变更文件；二进制、过大或冲突文件会保留条目并显示不能渲染的原因。

## 暂存、取消暂存和还原

- 在“未暂存”范围可以暂存文件。
- 在“已暂存”范围可以取消暂存。
- 还原操作只针对未暂存变化，并会弹出确认。

“还原文件”会永久丢弃跟踪文件的未暂存修改，或删除对应的未跟踪文件，无法撤销。执行前应核对路径，必要时先在外部工具中备份。

“审阅”使用短期一致性快照。如果项目被终端、Agent 或其他编辑器改变，旧快照会失效，界面需要刷新；不要根据旧差异重复执行操作。

当前“审阅”不提供 commit、branch、merge、pull 或 push 按钮。可以让 Agent 使用受管命令，或在右侧栏“终端”中手动操作，但两者都应遵循你的仓库流程。

## “文件”“终端”和 Agent 命令的区别

| 能力           | 谁操作 | 是否进入 Agent 历史 | 主要用途                   |
| -------------- | ------ | ------------------- | -------------------------- |
| 文件           | 用户   | 否                  | 安全只读预览               |
| 终端           | 用户   | 否                  | 交互式 shell               |
| Agent 文件工具 | Agent  | 是                  | 搜索、读取和受审批修改     |
| Agent 命令     | Agent  | 是                  | 非交互构建、测试和处理任务 |

Agent 不能隐式接管右侧栏“终端”。长时间运行的 Agent 命令由单独的受管会话跟踪，应用重启后也不能重新附着原来的操作系统进程。
