# 任务与对话

## 输入框快捷命令

在空白输入框键入 `/` 可以打开快捷命令，第一项是模型，后面包括压缩上下文、新聊天、创建聊天分支、能力中心、打开终端、内置浏览器、查看修改、子智能体、置顶或取消置顶、重命名、归档，最后两项依次是使用情况和计费、深浅主题切换。支持中文名称和英文别名筛选；鼠标悬停的行与方向键选中行都可以按 Enter 执行。不可用的命令会说明原因。

粘贴路径和恢复的草稿不会自动打开命令面板，执行命令不会把命令文字写入聊天。主动压缩和创建聊天分支只能在聊天空闲时使用，详情见[上下文与历史](context-and-history.md)。

### 选择模型

选择第一项“模型”（`model`）后，同一弹窗切换为模型列表。可选模型与输入框右下角的模型入口相同，每行显示模型 ID、厂商、上下文容量及文本或图片输入支持，便于区分不同配置。未单独设置上下文容量时，显示软件默认的 128K；容量值无效时显示“上下文未知”。

模型二级列表不提供筛选框。可以点击模型，或用方向键选择后按 Enter 切换；顶部返回按钮或 Escape 回到命令列表。选择模型仍沿用现有切换流程，运行中的限制、切换确认和跨厂商 API 的上下文处理规则保持不变，不会发送聊天消息或丢失附件。

### 打开工作面板

| 命令                    | 操作                                                 |
| ----------------------- | ---------------------------------------------------- |
| 打开终端（`terminal`）  | 在底部栏新建一个终端。每次执行都会新建。             |
| 内置浏览器（`browser`） | 在右侧栏新建一个空白浏览器标签页。每次执行都会新建。 |
| 查看修改（`review`）    | 打开当前项目的审阅页面；已有页面时直接切换过去。     |
| 子智能体（`agents`）    | 打开当前聊天的子智能体列表；已有页面时直接切换过去。 |

这些命令与对应工作面板使用相同的可用性检查。查看修改需要当前项目是 Git 仓库，子智能体列表需要当前聊天已有子智能体；条件不满足时隐藏对应入口，检查中则置灰并说明原因。面板关闭时会展开，已展开时直接显示目标页面；原有终端和浏览器标签会保留，已有审阅页面保留当前视图，子智能体页面从详情返回列表。窗口高度不足以容纳底部栏时，打开终端会置灰，增大窗口后即可使用。打开面板不会向模型发送消息，也不会停止当前运行。

### 切换深浅主题

主题命令只有一项，名称根据当前实际显示的主题变化：深色时显示“切为浅色主题”，浅色时显示“切为深色主题”。执行后切换整个应用的主题，与设置页的深浅模式选择保持一致。

如果之前选择了“跟随系统”，快捷切换会改为与当前实际主题相反的明确浅色或深色模式。浅色和深色模式仍分别沿用你在设置中已选的主题款式。

### 能力中心

选择“能力中心”后，同一面板会显示图片生成、联网搜索、人机交互、多智能体、浏览器自动化，以及 MCP 分组下已添加的服务器。可以搜索名称，使用鼠标或方向键选择，再点击开关或按 Enter 更改。顶部返回按钮或 Escape 返回快捷命令列表。开关操作不会关闭列表，也不会发送聊天消息或清除附件。

这些开关与设置页使用同一份配置，影响整个软件。Skill 仍在原有设置和输入框入口管理。缺少图片服务配置、搜索凭据或 MCP 启动授权时，会显示说明弹窗，点击“知道了”返回列表；配置和授权仍在设置中完成。

开关生效方式与设置页保持一致：关闭人机交互不妨碍回答已有问题；多智能体设置用于后续任务；关闭浏览器自动化或 MCP 可能停止当前连接或相关操作。能力中心没有统一延迟到下一轮生效的规则。

## 对话、轮次和运行

一个“对话”保存你与主 Agent 的连续工作历史。你每发送一次请求，就开始一个新的轮次；Agent 在这一轮中的模型调用、工具调用和审批过程构成一次运行。

同一个对话适合持续处理同一个目标。目标明显改变、历史已经过长，或你想保留一个分支方案时，可以新建对话或从某条回复“在新任务中继续”。

## 创建对话

1. 点击左侧栏“新对话”。
2. 选择项目或“不使用项目”。
3. 选择模型、权限，并按需添加附件和 Skill。
4. 输入目标后按 Enter；Shift+Enter 用于换行。

输入框草稿会保存到本机。不同对话和新对话页各自维护草稿；但草稿不是备份系统，不建议只把重要内容留在未发送状态。

## 写出容易执行的任务

一条实用的请求通常包含：

- 目标：最终希望得到什么。
- 范围：允许查看或修改哪些文件、服务或数据。
- 约束：不能做什么，需要先询问什么。
- 验收：用什么测试、格式或事实判断完成。

例如：

> 找出登录页加载慢的原因。只分析 `src/auth`，先不要改代码；给出证据、影响和两个修复方案。

这比“优化一下登录页”更容易得到可验证的结果。更多方法见[如何写清楚任务](../best-practices/writing-effective-tasks.md)。

## 运行中追加消息

Agent 还在工作时，新消息会进入“待处理消息队列”，而不是同时启动第二个根任务。你可以：

- 拖动消息调整顺序。
- 编辑或删除尚未提交的消息。
- 在可用时用“引导”把消息交给当前运行。

已交给当前运行、尚未处理的追加消息显示“已排队”。遇到审批时，这些消息会保留；审批通过后，即使工具仍在执行，也可以继续追加。Agent 会在当前工具批次完成、下一次请求模型前按接收顺序处理。

在任意队列消息的省略号菜单中，可以“打开队列自动发送”或“关闭队列自动发送”。开关对当前对话的整个队列生效，默认关闭；切换对话时各自保留状态，重新启动应用后需再次开启。

开启后，每次回复正常完成，都会按当前从上到下的顺序发送下一条，等待它回复完成后再继续。对话空闲时开启会立即发送第一条。关闭开关会保留剩余队列，当前回复继续完成；等待审批或用户输入时不会发送下一条，失败或手动停止会关闭自动发送，可再次开启以继续。

## 停止任务

输入框为空且 Agent 正在运行时，可以点击停止按钮。停止请求会尽快传递给模型和工具，但有三个边界：

- 已经提交的 FileChange 文件变更不会自动还原。
- 已经发送给网站、模型、MCP 或图片服务的请求可能已经产生效果或费用。
- 如果应用无法确认外部操作结果，界面可能提示结果未知；不要直接重复执行有副作用的步骤。

## 处理审批

默认权限下，文件编辑和命令通常会暂停等待你批准。FileChange 审批卡会显示最终完整差异；较大的差异可以分页查看。你可以批准、拒绝，部分创建或更新动作还允许仅在当前运行内记住同类许可；删除仍会单独询问。

详细规则见[权限与审批](permissions-and-approvals.md)。

## 消息操作

根据消息和运行状态，时间线中可以出现：

- 复制、收藏或取消收藏。
- 编辑最后一条已经完成的用户消息并重新执行该轮。
- 从一条已完成的助手回复“在新任务中继续”。
- 打开上一轮 Git 变更或生成的产物。
- 查看 token 用量；需先在“设置 → 用量与费用估算”开启对话 token 详情。

编辑最后一条用户消息会形成新的执行结果，不应把旧回复和新回复同时当作当前事实。任务仍在运行或等待审批时，不能安全编辑或切换某些状态。

“在新任务中继续”会创建一个带选定历史快照的新对话；它不会与原对话持续同步。若原任务还有命令正在运行，需要先等待或关闭命令。

## 创建聊天分支

聊天空闲时，在空白输入框键入 `/`，选择“创建聊天分支”；可以输入“分支”或 `fork` 筛选。这项命令从执行时的最新安全完整位置创建分支，包含当时可用的上下文和模型选择。没有完整回复时，命令会显示“暂无完整回复可供分支”。

手动压缩成功后的分割线右侧也有分支按钮。它从该次压缩完成的历史位置创建分支，包含那次压缩的摘要，不包含其后的新消息；后续聊天不会改变这个固定位置。从某条回复“在新任务中继续”则仍以那条回复为边界。

这些入口都需要聊天空闲；运行、等待审批、后台命令或上下文操作未结束时暂不可用。创建分支不会重复计算已有历史的用量和费用，新旧聊天之后各自继续。

## 搜索和整理

左侧栏提供：

- 按文字搜索本地聊天标题和内容。
- 按创建时间或最近更新时间整理对话。
- 置顶项目或对话。
- 重命名、标记未读和归档。
- 按项目批量归档对话。

归档不会立即删除内容。可以在“设置 → 已归档对话”按项目筛选、取消归档，或永久删除单条/全部记录。永久删除无法从界面撤销。

## 系统通知

普通根任务可以在完成、失败、取消或等待审批时发送原生系统通知，其事件预设在“设置 → 常规”中配置；Automation 使用每项任务自己的触发策略。提示音和内容预览是两类通知共用的全局设置。通知只是提醒，权威状态仍以实际对话或“已安排”页面为准。详见[系统通知](../capabilities/notifications.md)。

## 项目和对话的关系

项目为对话提供文件夹边界，但对话仍是独立历史。移除项目会永久删除 Captain Who 保存的项目、相关本地对话和附件记录；项目目录中的真实文件不会被修改。

Scheduled Automation 创建的“新聊天”也会出现在对话列表；删除 Automation 不会删除它以前创建的聊天。

## 当前限制

- 没有跨设备对话同步。
- 搜索是本地文字检索，不是通用语义搜索。
- 运行中的外部副作用没有统一撤销功能。
- 普通用户不能直接在子 Agent 的只读对话中发送消息。
