# 联网搜索与浏览器

MyCopilot 的“搜索”和“浏览器”包含几种不同能力，权限和数据流并不相同。

## 快速区分

| 能力           | 用途                 | 数据会去哪里                       |
| -------------- | -------------------- | ---------------------------------- |
| 左侧栏搜索     | 查找本地对话         | 留在本机                           |
| Agent 联网搜索 | 搜索公开网络资料     | 查询发送到 Tavily                  |
| Agent 网页读取 | 读取指定网页正文     | 目标 URL 发送到 Tavily             |
| 右侧栏浏览器   | 用户手动浏览         | 直接连接访问的网站                 |
| 浏览器自动化   | Agent 操作受管浏览器 | 连接网站，并经过额外授权与风险检查 |

## 搜索本地聊天

点击左侧栏“搜索”，输入关键词。结果会显示对话标题、命中片段和所属项目；选择结果会打开对应对话。

这是本地文字搜索，不会把查询发送给 Tavily，也不是按语义相似度检索。

## 配置 Agent 联网搜索

1. 打开“设置 → 配置”。
2. 找到“联网搜索”。
3. 填写 Tavily API Key。
4. 打开联网搜索开关。

没有 Key 时，界面不会允许开启。关闭开关或清空 Key 后，Agent 不再获得 Tavily 搜索能力。

任务示例：

> 搜索最近一个月这个库的官方发布说明，只使用官方来源；列出版本、发布日期和链接，并区分已确认事实与推断。

Agent 可以使用“联网搜索”找结果，再用“读取网页”查看具体页面。搜索摘要可能不完整，涉及版本、价格、政策或安全信息时，应要求它打开原始来源并给出链接。

## 手动使用右侧栏浏览器

1. 打开右侧栏“新建面板 → 浏览器”。
2. 在地址栏输入 HTTP 或 HTTPS 地址。
3. 使用前进、后退、刷新、缩放、新选项卡和下载中心。
4. 浏览器菜单可以打开浏览历史和浏览器设置；需要退出网站账户或清理 Cookie 时，选择“清除浏览数据”。

浏览器使用独立且持久的会话。Cookie、站点存储和缓存会在标签页与应用重启之间保留，浏览历史和下载记录由 Rust Core 持久保存。清除数据时可以选择类别与时间范围；下载历史当前只能按全部时间清除，删除历史不等于删除磁盘文件。

在“设置 → 浏览器”可以选择应用内链接默认交给系统浏览器还是内置浏览器，并设置下载目录与“手动下载前询问保存位置”。该询问仅适用于用户发起的下载，Agent 下载始终使用受管目录。

为降低风险，网页申请摄像头、麦克风、定位、系统通知等权限时会被拒绝；任意自定义协议也不受支持。合法的新窗口链接会在受管的新页面中打开，而不是获得普通系统弹窗。

## 什么时候需要浏览器自动化

联网搜索适合“找资料和读页面”；浏览器自动化适合“点击、填写、翻页、截图、上传或下载”。它只控制 MyCopilot 右侧栏中的受管浏览器，不会连接系统浏览器。

启用和使用步骤见[浏览器自动化](../capabilities/browser-automation.md)。即使已经手动登录网站，Agent 仍需获得能力授权，敏感操作还可能单独审批。

## 隐私和安全提示

- 不要在任务中粘贴 Tavily Key、网站密码或 Cookie。
- 网页内容可能包含诱导 Agent 泄露信息或执行危险操作的提示；它仍是不可信输入。
- 自动化访问 localhost、私网、下载、上传、存储、脚本等目标时可能要求审批或被拒绝。
- 清除浏览数据会清理受管浏览器的缓存、站点数据和图标缓存，不会删除对话历史。

## 当前限制

- Agent 联网搜索当前只接入 Tavily，没有其他搜索服务选择器。
- 浏览器只支持 HTTP/HTTPS 和受控 PDF 查看路径。
- 网站权限请求全部拒绝，部分依赖摄像头、定位或通知的网站功能不能使用。
- 下载是已保存到配置目录的持久文件；截图等其他 Browser Artifact 仍可能只在当前 Run 中有效。
