# 回答智能体的问题

Agent 需要你补充信息、表达偏好、作出判断、提供反馈或亲自完成某个操作时，可以在聊天输入区打开“交互”面板。你也可以明确要求 Agent 发起交互。面板显示时占据普通输入框的位置；收起或结束后恢复输入框，保留原草稿与附件。普通单 Agent 聊天也支持提问。工具是否可用由“设置 → 个性化 → 人机交互 → 允许智能体向人类提问”控制，默认开启。

## 逐题填写，整批提交

交互内容可以是问题，也可以是具体协助请求。选项根据当前事项设计，没有固定回答模板；你可以选择合适的回应，也可以用自己的文字说明情况。

1. 一页显示一道题，使用顶部左右箭头翻页。
2. 每题选择一个选项、在“自定义回答”一行填写文字，或者点击底部“跳过”（选中后显示“已跳过”）。三种方式互斥，可以在提交前修改。
3. 当前题处理后可点击右下角“下一题”前往未处理题；所有题都处理完成后，按钮变为“提交”。顶部箭头可随时回看修改，翻页不会发送答案。
4. 点击“提交”一次发送整批。成功后面板和该批回答入口消失，聊天中显示一条按题序组合问题与答案的用户消息；跳过项显示“已跳过”。

提交后的答案不能重新编辑或补答；需要补充时可发送普通消息。提交失败时保留本窗口的页码和草稿。结果暂时无法确认时，使用原按钮重试，系统会核验同一次提交，不会重复发送。

中文输入法确认、文字输入框中的 Enter 和 Escape 都不会提交整批、跳过问题或停止运行。主聊天输入框保持独立，普通消息不会自动被解释为问题答案。

## 两种提问方式

**需要等待你参与的交互**会暂停当前 Agent Run。提交后，Agent 在原任务中从提问位置继续；等待时不能为同聊天另开运行、切换模型、压缩或创建分支。这类问题没有“忽略全部”，可以逐题选择“跳过”后统一提交。

**非阻塞交互**允许 Agent 继续处理不依赖你回应的工作。同聊天可以保留多批未答问题，新批次先显示；旧批次仍在聊天中保留一个“交互 · 共 N 题”入口。入口按照提问工具实际调用顺序插入回复，位于调用前后的文字之间；每批不按题目拆成多个入口。

非阻塞面板右上角可以最小化。点击聊天中的对应入口可恢复页码和草稿。左下角“忽略全部”只结束当前批次，不发送草稿或消息，也不会唤醒 Agent。系统会在普通历史中记录这次忽略，Agent 在下一次正常工作时获知，不会立即额外运行。逐题“跳过”再提交是一条正式回复，与忽略全部不同。

运行已经结束时仍可回答非阻塞问题。提交会在同聊天中发起后续运行；运行中提交则由系统在安全边界送入当前工作。审批或其他需要暂停的状态下，已提交答案会先保存，等待合法时机投递。

## 审批优先与恢复

显示顺序为审批、必要的阻塞问题、非阻塞问题。审批期间不能切回答题；处理完后恢复尚未提交的问题。批次切换和抢占保留当前窗口的草稿，前端显示顺序不会改变后端已提交回答的接纳顺序。

同版本重启后，系统可重新载入未答问题和已提交回答；未提交的文字、选项和页码只保存在当前窗口内存，关闭窗口或重载页面会丢失这些草稿。其他窗口提交或忽略后，本窗口的该批入口也会撤下。

如果重启时无法确定恢复期间的模型请求或工具是否已执行，系统会保守结束该次恢复，不自动重复可能收费或有副作用的请求。先核对聊天和实际工作状态，再明确发起后续任务。

关闭提问开关只影响新提问，不删除已有问题。所有层级子 Agent 和无人值守定时运行不能调用提问工具；回答或跳过问题也不会授予文件、命令等权限。
