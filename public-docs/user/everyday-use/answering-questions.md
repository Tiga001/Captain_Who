# 回答智能体的问题

当 Agent 缺少你独有的信息、需要你的偏好或判断，或者确实需要你亲自完成一项操作时，它可以在当前对话中打开“人机交互”面板。你也可以明确要求它向你提问。这个能力默认开启，可在“设置 → 个性化 → 人机交互”中关闭。

问题是为了让你参与任务，不是权限授权。无论你选择、填写、跳过还是忽略，Agent 都仍须按当前权限和审批规则执行文件、命令、网络或其他操作。

## 两种提问方式

| 方式       | 什么时候出现                         | Agent 在等待时做什么           | 你回答后发生什么                                         |
| ---------- | ------------------------------------ | ------------------------------ | -------------------------------------------------------- |
| 阻塞提问   | 没有你的回答就不能安全或有意义地继续 | 当前任务暂停，等待你处理       | 原任务从提问处继续                                       |
| 非阻塞提问 | Agent 仍可完成不依赖答案的工作       | 当前任务继续，问题保留在对话中 | 答案会在安全时机送入当前任务；任务已结束时会继续同一对话 |

例如，Agent 必须知道要修改哪个分支时，应使用阻塞提问；它可以一边阅读项目、一边询问你偏好的文档格式时，应使用非阻塞提问。

非阻塞不表示 Agent 已得到你的同意，也不表示所问事项已经完成。它只表示 Agent 可先做其他独立工作。当前没有自动答题超时：问题会一直保留，直到你处理、忽略（仅非阻塞问题）或阻塞任务被停止。

只有你直接使用的根 Agent 可以提问。子 Agent 和无人值守的 Scheduled Automation 不会向你打开此类问题。

## 如何逐题回答

每次提问是一批问题。请处理完这一批后一次提交：

1. 一页显示一道题，使用顶部左右箭头查看其他题目。
2. 对每题选择一个建议选项、填写“自定义回答”，或点击“跳过”。三种方式互斥，提交前可随时修改。
3. 当前题处理后点击“下一题”前往未处理项；所有题都处理完成后，按钮变为“提交”。
4. 点击“提交”后，整批答案一次发送。聊天会显示一条按题序组合的问题与答案；跳过项显示“已跳过”。

输入框内的 Enter、Escape 和中文输入法确认不会提交、跳过、忽略或停止任务。普通聊天输入框也不会自动被当作问题答案。

提交后的回答不能编辑或补答；如果需要补充，请发送普通消息。所有题都选择“跳过”后再提交，仍是正式回答，Agent 会据此继续或说明缺少什么条件。

## 非阻塞问题：最小化与忽略

非阻塞问题允许同时保留多批。新批次优先显示；较早批次会在聊天时间线中保留一个“交互 · 共 N 项”入口。点击入口可以恢复对应问题和当前草稿。

你可以点击面板右上角的最小化按钮，把非阻塞问题暂时收起。最小化不会回答、取消或忽略问题，也不会停止 Agent。

如果你不想处理一整批非阻塞问题，点击“忽略全部”。这只结束当前批次：不会发送你的草稿、不会把它当作普通聊天消息，也不会为了忽略额外启动 Agent。Agent 会在下一次正常工作时知道这批问题被忽略。阻塞问题没有“忽略全部”；请逐题选择“跳过”后提交。

## 暂停、审批与恢复

显示优先级是：审批 > 阻塞问题 > 非阻塞问题。审批出现时，问题面板会暂时让位；处理审批后可继续处理原问题，未提交草稿会保留在当前窗口内。

阻塞问题会让当前对话处于等待状态。在此期间不能在同一对话另发一条新任务、切换模型、手动压缩上下文或创建分支。停止这个等待任务会取消该阻塞问题，之后不能再提交它。

停止任务不会自动删除尚未回答的非阻塞问题。已经提交但尚未送入模型的答案可能因停止而不再投递；应用不会为避免重复或未知副作用而擅自重放。请先核对对话和实际结果，再明确发送新的任务。

未处理的问题、已提交的回答和投递状态会保存在本机，并可在同版本重启后重新读取。尚未提交的选项、文字和页码只保存在当前窗口内存；关闭窗口或重载页面会丢失这些草稿。

## 提交失败或需要登录时

提交时，应用会先保存和核对一次性答案，避免重复发送。若结果暂时无法确认，不要重新填写或更改内容；使用原按钮重试，应用会识别同一次提交。

当非阻塞问题的原任务已经结束、你的回答需要启动新的后续任务时，Captain Who 会先验证账户登录和软件许可。如果出现登录或许可提示，请完成验证后回到同一对话再次提交；这时答案尚未被静默保存为已提交状态。

如果看到“状态已变化”或无法加载问题，请刷新当前对话后确认面板和聊天记录，再决定是否继续。已提交的答案不会变回可编辑问题。

## 可见性与数据

问题和回答显示在当前 Conversation 的面板与时间线入口中。当前应用不会仅因为 Agent 提出问题而额外发送系统原生通知；请在对话内处理它们。

问题、正式回答和必要的运行状态保存在本机的对话数据中。它们可能作为任务上下文发送给你选定的模型服务商；如果 Agent 按你的要求使用搜索、浏览器或 MCP，相关第三方也可能接收完成该操作所需的内容。具体边界见[数据与权限](../../security/data-and-permissions.md)。
