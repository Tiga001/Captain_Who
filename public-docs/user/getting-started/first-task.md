# 完成第一个任务

这个练习不要求选择项目，也不会修改文件。它用来确认模型连接、消息发送和任务停止都能正常工作。

## 1. 确认模型可用

如果还没有配置模型：

1. 点击左侧栏底部的个人资料区域，选择“设置”。
2. 进入“配置”，填写 API URL 和 API Token。
3. 确认至少一个模型处于启用状态；模型标识必须是你的服务实际接受的值。
4. 点击“返回应用”。

不要把 Token 粘贴到聊天内容里。连接配置和聊天消息是不同的数据边界。

## 2. 新建对话

1. 点击左侧栏顶部“新对话”。
2. 项目选择“不使用项目”。
3. 选择刚配置的模型。
4. 权限保留“默认权限”。

默认权限不会妨碍普通问答，同时可以避免任务无意访问工作区外的文件或自动执行写入。

## 3. 发送一个可验证的请求

在输入框中输入：

> 请用三点说明：普通聊天模型和 Agent 的区别。每点先给结论，再给一个日常工作示例。不要调用外部工具。

按 Enter 发送。你应该看到 Agent 开始处理，并最终返回一段结构化回答。

如果一直没有回复：

- 检查模型服务的 URL、Token 和模型标识。
- 确认网络能访问该服务。
- 查看错误提示属于鉴权、额度、服务不可用还是响应不兼容。
- 回到设置修正后，再创建新任务或重试。

## 4. 认识运行中的输入框

Agent 正在运行时：

- 在输入框中发送新内容，会先进入“待处理消息队列”。
- 队列中的消息可以排序、编辑或删除；“引导”会把合适的消息交给当前运行。
- 输入框为空时可以点击停止按钮，请求终止当前运行。

停止是一个请求，不是事务回滚。如果某个工具此前已经写入文件、运行命令或向第三方发送请求，应检查真实结果。

## 5. 管理这次结果

任务完成后，可以：

- 复制或收藏消息。
- 编辑最后一条用户消息并重新执行这一轮。
- 从某条已完成的助手回复“在新任务中继续”，创建一个带历史快照的新对话。
- 在左侧栏置顶、重命名或归档对话。
