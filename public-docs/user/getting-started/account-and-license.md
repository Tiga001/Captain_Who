# 账户与软件许可

Captain Who 的登录身份和模型服务账户是两件事。启动新的 Agent 回合前，需要有效的登录状态和应用内使用许可；当前源码既支持云端账户，也支持内置本地账户。模型服务仍需自行配置。

这里的“软件许可”指应用内启动新回合的使用资格，不是源码的 [Apache License 2.0](../../legal/README.md)，也不包含模型 API 额度。

## 登录账户

首次启动时，应用会要求登录。进入主界面后，也可以打开左下角账户菜单，选择“登录”。

### 当前源码 / 开发构建：内置本地账户

当前仓库源码支持以下本地登录方式；这不代表官网已发布的安装包一定包含该功能，安装包用户应以所用版本实际提供的登录方式为准。

1. 在登录页选择“账号密码”。
2. 在“账号或邮箱”中输入 `captainwho`，密码也输入 `captainwho`，再点击“登录”。
3. 登录后显示名称为“大副”，软件许可为长期有效。

这是公开提供的本地账户，不是个人云端身份。它不需要官网注册，不访问云端身份或在线许可服务；本机会记住登录状态，退出登录后需要重新登录。本地登录只提供本机应用使用资格，不提供模型 API 额度，也不改变工具权限或审批规则。

### 云端账户：邮箱密码或验证码

使用云端账户时，仍按以下流程登录并检查软件许可：

1. 输入邮箱后，选择密码登录，或切换到邮箱验证码登录。
2. 使用验证码登录时，先请求验证码，再输入收到的代码完成验证。
3. 需要注册或重置密码时，使用登录页中的相应入口；它会打开官网账户页面。
4. 登录成功后，左下角账户菜单会显示账户资料和软件许可状态。

云端账户资料页显示当前账户的显示名称和邮箱；“编辑资料”会打开官网，“刷新”会重新读取资料。不要把模型 API Token 当作账户密码输入，也不要把个人账户密码或验证码写入聊天、项目文件或截图。

## 检查软件许可

在“设置 → 个人资料 → 软件许可证”中可以查看状态。当前源码的内置本地账户登录后即有长期有效的本地使用许可，无需在线验证。云端账户在需要时可点击“验证许可证”，常见状态包括：

- **有效**：可以启动新的 Agent 回合。
- **未登录**：先登录账户。
- **不可用**：账户当前没有可用许可；使用“管理许可证”进入账户页面处理。
- **暂时无法验证**：检查网络后重新验证。一次网络或服务错误不表示许可已经失效。

许可检查只决定能否开始新的回合，不会替你配置模型、提供模型额度，也不会改变已经在运行的任务。模型连接仍需按[模型与服务商](../everyday-use/models-and-providers.md)单独设置。

## 退出登录

在左下角账户菜单选择“退出登录”。退出后不能启动新的 Agent 回合，直到再次登录并取得可用许可；内置本地账户重新登录后即可恢复本地使用资格。退出登录不是清除本机工作数据的操作：项目、对话、文件和模型配置仍按照各自的本机保留与删除规则处理。

## 数据边界

云端账户的资料、登录会话和软件许可校验会与 Captain Who 的账户服务交互；内置本地账户的登录与许可不使用这些云端服务。两种登录方式都不会因为登录而把项目文件、对话、Prompt、Agent 执行记录、模型密钥或本机 Token 活动同步到 Captain Who。

发送给模型、联网搜索、网页或 MCP 服务的数据仍会到达你主动选择的相应服务。开始处理敏感信息前，请先核对这些服务的政策和组织规则。更完整的说明见[数据与权限](../../security/data-and-permissions.md)。
