# 账户与软件许可

Captain Who 账户和模型服务账户是两件事。账户用于登录和软件许可校验；模型服务账户用于调用你自行配置的模型 API。启动新的 Agent 回合前，必须同时满足“已登录 Captain Who 账户”和“软件许可可用”。

## 登录账户

首次启动时，应用会要求登录。进入主界面后，也可以打开左下角账户菜单，选择“登录”。

1. 输入邮箱后，选择密码登录，或切换到邮箱验证码登录。
2. 使用验证码登录时，先请求验证码，再输入收到的代码完成验证。
3. 需要注册或重置密码时，使用登录页中的相应入口；它会打开官网账户页面。
4. 登录成功后，左下角账户菜单会显示账户资料和软件许可状态。

账户资料页显示当前账户的显示名称和邮箱；“编辑资料”会打开官网，“刷新”会重新读取资料。不要把模型 API Token 当作账户密码输入，也不要把账户密码或验证码写入聊天、项目文件或截图。

## 检查软件许可

在“设置 → 个人资料 → 软件许可证”中可以查看状态，并在需要时点击“验证许可证”。常见状态包括：

- **有效**：可以启动新的 Agent 回合。
- **未登录**：先登录账户。
- **不可用**：账户当前没有可用许可；使用“管理许可证”进入账户页面处理。
- **暂时无法验证**：检查网络后重新验证。一次网络或服务错误不表示许可已经失效。

许可检查只决定能否开始新的回合，不会替你配置模型、提供模型额度，也不会改变已经在运行的任务。模型连接仍需按[模型与服务商](../everyday-use/models-and-providers.md)单独设置。

## 退出登录

在左下角账户菜单选择“退出登录”。退出后不能启动新的 Agent 回合，直到再次登录并完成许可校验。退出登录不是清除本机工作数据的操作：项目、对话、文件和模型配置仍按照各自的本机保留与删除规则处理。

## 数据边界

账户资料、登录会话和软件许可校验会与 Captain Who 的账户服务交互。相对地，项目文件、对话、Prompt、Agent 执行记录、模型密钥和本机 Token 活动保留在设备上，不会因为登录账户而同步到 Captain Who。

发送给模型、联网搜索、网页或 MCP 服务的数据仍会到达你主动选择的相应服务。开始处理敏感信息前，请先核对这些服务的政策和组织规则。更完整的说明见[数据与权限](../../security/data-and-permissions.md)。
