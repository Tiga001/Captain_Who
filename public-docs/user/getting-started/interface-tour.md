# 界面导览

Captain Who 的主界面可以理解为三块：左侧管理工作，中间与 Agent 协作，右侧查看和操作工具。

## 左侧栏：选择工作

左侧栏顶部有三个常用入口：

- **新对话**：开始一个新的主对话。
- **搜索**：按文字搜索本地聊天标题和内容，并跳回匹配对话。
- **已安排**：管理 Scheduled Automation；角标表示有任务需要关注。

下方按“置顶”“项目”和“对话”组织记录。项目区标题旁可以直接从文件夹创建项目；对话可以置顶、重命名、归档或标记为未读，项目可以新建对话、置顶、在文件夹中显示、重命名、批量归档对话或移除。

“移除项目”会删除 Captain Who 中这个项目的本地对话和附件记录，但**不会删除项目文件夹里的文件**。这是不可逆的数据操作，确认前请仔细阅读弹窗。

左侧栏底部显示本地个人资料。点击后可以进入“设置”。

## 中间区域：任务与对话

新对话页会询问“我们应该构建什么？”。输入框周围可以配置：

- 项目：选择已有项目、不使用项目，或通过系统文件夹选择器新建项目。
- 模型：从已启用且连接信息完整的模型中选择。
- 权限：默认、完全或自定义；后两项是否出现取决于“设置 → 常规”。
- 附件：点击“添加上下文（+）”选择文件或图片，也可以拖放或粘贴文件。
- Skill：从“添加上下文（+）→ 技能”选择本次运行要使用的能力包。

按 Enter 发送，Shift+Enter 换行。Agent 运行时，发送按钮可以用于把新消息加入队列；如果输入框为空，按钮用于停止当前生成。停止不会撤销已经完成的外部操作。

对话时间线会展示回复、工具活动、文件修改、命令、审批、计划和产物。可用操作包括复制、收藏、编辑最后一条已完成的用户消息，以及从某条已完成回复“在新任务中继续”。

## 右侧栏：辅助工作台

右侧栏的“新建面板”可以打开：

- **终端**：面向用户的真实终端，会话固定在创建时的项目目录。
- **浏览器**：应用内的受管浏览器，支持多个页面、历史和下载中心。
- **文件**：项目目录树和只读预览。
- **审阅**：Git 变更、差异、暂存、取消暂存和还原。
- **子智能体**：仅在当前任务已经产生子 Agent 时出现，用于查看状态和只读对话。

右侧栏页面可以切换、关闭、调整宽度或最大化。当前页面栈和大多数页面状态只在本次应用会话中保留；重启后不保证恢复。

## 设置：配置能力边界

设置当前包括：

- 常规：语言、普通任务系统通知、权限模式和自定义权限。
- 个人资料、外观、个性化：本地显示和默认回复偏好。
- 配置：模型、联网搜索和图片生成。
- 用量与费用估算：本地 token 统计与估算。
- 技能、子智能体、MCP 服务器：扩展 Agent 能力。
- 浏览器：链接打开位置、下载目录、浏览/下载历史和数据清理。
- 环境：管理项目。
- 已归档对话：恢复或永久删除聊天。

设置页顶部可以搜索页面名称。MCP 编辑器有未保存变更保护；离开前会询问是否放弃。
