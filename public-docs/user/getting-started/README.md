# 快速开始

本节提供一条从零开始、可以按顺序操作的路径。

## 学习顺序

1. [产品概览](product-overview.md)：了解适用场景和当前边界。
2. [安装与首次启动](installation.md)：从官网获取正式安装包并启动应用。
3. [账户与软件许可](account-and-license.md)：登录并确认可以启动新的 Agent 回合。
4. [界面导览](interface-tour.md)：认识左侧栏、对话区、输入框、右侧栏和设置。
5. [完成第一个任务](first-task.md)：配置模型并进行一次不修改文件的对话。
6. [使用第一个项目](first-project.md)：选择一个或多个本地文件夹，让 Agent 理解并协助处理项目。

完成后，你可以前往[日常使用](../everyday-use/README.md)学习管理对话和文件，或从[能力指南](../capabilities/README.md)选择 Skill、MCP、Multi-Agent 等进阶能力。

## 开始前准备

- 从 [Captain Who 官网](https://captainwhoagent.com/) 下载的正式 macOS Apple Silicon 安装包；当前公开版本要求 macOS 12 或更高版本。
- 一个 Captain Who 账户和可用的软件许可；二者是启动新 Agent 回合的前置条件，不等同于模型服务账户。
- 一个兼容的模型 API 地址、Token 和模型标识；新安装不会预置可选模型，需要先手动添加并启用。
- 如果要使用联网搜索，一枚 Tavily API Key。
- 如果要处理项目，一个你有权访问和修改的本地文件夹。

建议第一次使用时选择“默认权限”，并先让 Agent 只读分析。确认工作方式后，再按任务需要开启更高权限。
