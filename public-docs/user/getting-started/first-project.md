# 使用第一个项目

在 MyCopilot 中，“项目”是一个经过你选择的本地文件夹。它为文件工具、命令、右侧栏和项目专属 Skill 提供明确的工作区边界。

## 1. 添加项目

1. 点击“新对话”。
2. 打开输入框下方的项目选择器。
3. 选择“新建项目”，再通过系统对话框选择一个文件夹。
4. 确认页面标题中显示该项目名称。

你也可以在“设置 → 环境”中添加或移除项目。选择项目不会自动修改或上传文件。

## 2. 先做只读理解

选择“默认权限”，然后发送：

> 请先只读了解这个项目。概述它解决的问题、主要目录、启动入口和测试方式；不要修改文件，也不要安装依赖。如果现有信息不足，请明确指出。

Agent 可以使用文件列表、搜索和读取工具。若它提出运行命令，默认权限会显示审批；第一次练习可以拒绝，并在拒绝说明中要求它只根据文件回答。

## 3. 在右侧栏核对

打开右侧栏“文件”：

1. 展开目录树或用筛选框查找文件。
2. 点击文本、Markdown、图片或 PDF 进行只读预览。
3. Markdown 可以切换源代码与预览。
4. 需要时复制文件地址，或在系统文件夹中显示。

“文件”不提供编辑、删除或重命名。Office 文件在这里不会渲染，需要用外部应用打开，或通过相应 Skill 交给 Agent 处理。

## 4. 尝试一个小修改

选择一个可丢弃或已经纳入版本控制的练习项目，发送：

> 请在 README 中增加一个简短的“本地运行”小节。先说明计划，只修改这个文件，完成后总结具体变化。

默认权限下，Agent 提交文件修改时会显示审批。审批前核对目标文件和变更摘要；批准后，再打开右侧栏“审阅”检查“上一轮”或“未暂存”差异。

如果这是 Git 仓库，“审阅”还可以：

- 查看统一或分栏差异。
- 暂存未暂存文件，或取消暂存已暂存文件。
- 还原未暂存更改；此操作会永久丢弃对应更改，必须再次确认。

MyCopilot 当前不在“审阅”中提供 commit 或 push 按钮。

## 5. 理解项目生命周期

- 项目中的对话会显示在该项目下。
- 项目专属 Skill 来自项目内的 `.agents/skills/`，离开项目后不会出现。
- 右侧栏终端和文件页绑定到创建时的项目；切换项目不会悄悄改变旧终端的目录。
- “移除项目”会永久删除 MyCopilot 保存的该项目对话与附件记录，但不会删除文件夹内容。
