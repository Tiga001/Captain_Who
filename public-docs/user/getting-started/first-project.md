# 使用第一个项目

在 Captain Who 中，“项目”由一个或多个经过你选择的本地文件夹组成。它为文件工具、命令、右侧栏和项目专属 Skill 提供明确的工作区边界；选择项目不会自动上传或修改其中的文件。

## 1. 添加项目

1. 点击“新对话”。
2. 打开输入框下方的项目选择器。
3. 选择“新建项目”，再通过系统对话框选择第一个文件夹。
4. 确认页面标题中显示该项目名称。

第一个文件夹会成为“主要”文件夹。之后可从项目的“编辑项目”中添加更多文件夹、调整主要文件夹或移除不再需要的文件夹。一个项目最多可包含 32 个文件夹，必须保留且只保留一个主要文件夹；重复或彼此嵌套的文件夹不能同时加入同一项目。

你也可以点击左侧栏“项目”标题旁的文件夹按钮，或在“设置 → 环境”中添加、编辑或移除项目。

## 2. 先做只读理解

选择“默认权限”，然后发送：

> 请先只读了解这个项目。概述它解决的问题、主要目录、启动入口和测试方式；不要修改文件，也不要安装依赖。如果现有信息不足，请明确指出。

Agent 可以使用文件列表、搜索和读取工具。若它提出运行命令，默认权限会显示审批；第一次练习可以拒绝，并在拒绝说明中要求它只根据文件回答。

## 3. 在右侧栏核对

打开右侧栏“文件”：

1. 展开目录树或用筛选框查找文件。
2. 点击文本、Markdown、图片或 PDF 进行只读预览。
3. Markdown 可以切换源代码与预览。
4. 需要时复制文件地址，或在系统文件夹中显示。

“文件”不提供编辑、删除或重命名。Office 文件在这里不会渲染，需要用外部应用打开，或通过相应 Skill 交给 Agent 处理。

## 4. 尝试一个小修改

选择一个可丢弃或已经纳入版本控制的练习项目，发送：

> 请在 README 中增加一个简短的“本地运行”小节。先说明计划，只修改这个文件，完成后总结具体变化。

默认权限下，Agent 提交 FileChange 时会显示分栏或分页 Diff 审批。审批前核对目标文件和完整变更；批准后，可以在时间线重新打开持久审阅卡，再到右侧栏“审阅”检查“上一轮”或“未暂存”差异。

如果这是 Git 仓库，“审阅”还可以：

- 查看统一或分栏差异。
- 暂存未暂存文件，或取消暂存已暂存文件。
- 还原未暂存更改；此操作会永久丢弃对应更改，必须再次确认。

Captain Who 当前不在“审阅”中提供 commit 或 push 按钮。

## 5. 理解项目生命周期

- 项目中的对话会显示在该项目下。
- 多文件夹项目以主要文件夹作为默认工作目录；文件、终端和 Git 审阅可在界面提供选择时切换到项目内的其他文件夹。向 Agent 描述任务时应写清它应处理哪个文件夹。
- 项目专属 Skill 来自项目内的 `.agents/skills/`，离开项目后不会出现。
- 右侧栏终端和文件页绑定到创建时的项目；切换项目不会悄悄改变旧终端的目录。
- “移除项目”会永久删除 Captain Who 保存的该项目对话与附件记录，但不会删除任何已选择文件夹的内容。
