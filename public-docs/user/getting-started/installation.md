# 安装与首次启动

## 当前发行状态

截至 2026-08-31，Captain Who 仍是私有开发项目，**尚未提供公开下载、自动更新或统一发布渠道**。仓库虽然配置了 macOS、Windows 和 Linux 的打包目标，但这不等于每个平台已经通过正式发行验证。

如果你是受邀测试用户，请只使用团队成员直接提供、并附有明确版本和校验信息的安装包。不要从转载链接或不明镜像获取构建。

## 安装包形式

实际可用格式以可信分发方随安装包提供的版本说明为准。当前构建配置可以生成：

| 平台    | 可能提供的格式        | 安装方式                         |
| ------- | --------------------- | -------------------------------- |
| macOS   | `.dmg` / `.app`       | 打开 DMG，按随安装包说明完成安装 |
| Windows | NSIS `.exe`           | 运行安装程序并核对发布者信息     |
| Linux   | AppImage、snap 或 deb | 按发行版要求和随安装包说明安装   |

不要因为文件扩展名正确就忽略操作系统的签名或来源警告。当前 macOS 正式构建流程强制 Developer ID、hardened runtime、应用/受管原生组件和 DMG 签名验证，但尚未配置 Apple 公证；Windows/Linux 的签名和发行验收也要按收到的具体安装包判断。若系统阻止安装，先停止操作，向安装包的直接提供者核对来源、版本和校验值；不要直接关闭系统安全机制。

## 首次启动

应用启动后会先加载本地服务、项目、模型设置、草稿和对话记录。首次启动或新版本首次运行可能需要更长时间；如果启动页显示失败，可以先点“重试”。

进入主界面后，先完成模型配置：

1. 点击左侧栏底部的个人资料区域，再选择“设置”。
2. 打开“配置”。
3. 填写模型默认使用的 API URL 和 API Token。
4. 新安装默认没有预置模型条目；进入“管理模型”新增服务实际提供的模型 ID，再启用它。
5. 返回应用，创建“新对话”，确认输入框下方能选到该模型。

模型名称出现在列表中并不代表接口已经可用。Captain Who 只有在发起真实请求时才能验证地址、Token、模型标识和服务端兼容性。

完整字段说明见[模型与服务商](../everyday-use/models-and-providers.md)。

## 可选配置

- 联网搜索：在“设置 → 配置”中填写 Tavily API Key，再开启“联网搜索”。
- 权限：在“设置 → 常规”中决定是否开放“完全权限”或“自定义权限”。第一次使用建议保留默认权限。
- 语言与通知：在“设置 → 常规”中选择界面语言，配置普通任务的通知条件，以及普通任务与 Automation 共用的提示音和内容预览。
- Skill：内置 Skill 可直接从任务输入框选择；第三方 Skill 在“设置 → 技能”中安装。
- MCP：本地 MCP 服务器在“设置 → MCP”中单独添加、授权和启用。

## 更新与卸载

当前没有应用内自动更新。更新时仍以可信分发方随安装包提供的版本说明和校验信息为准。更新前先让正在运行的任务结束，并备份重要项目文件；更新后先完成一次模型连接和项目读取检查。

卸载应用不等于擦除全部本地数据。若要先清理界面可管理的内容，可以逐个移除项目，把剩余对话归档，再到“设置 → 已归档对话”执行永久删除。当前没有“一键清空全部应用数据”的入口，模型配置、凭据和其他应用数据可能继续保留；不要猜测并删除系统目录中的文件。
