# 安装与首次启动

## 当前正式发行

Captain Who 当前正式版本为 **1.0.5**。请只从 [Captain Who 官网](https://captainwhoagent.com/) 下载；不要使用转载链接、网盘镜像或他人转发的安装包。公开的[开发仓库](https://github.com/Tiga001/Captain_Who)会持续更新，但不是当前安装包的下载入口。

当前公开下载与支持范围如下：

| 平台                               | 当前状态         | 获取方式                         |
| ---------------------------------- | ---------------- | -------------------------------- |
| macOS 12 及更高版本、Apple Silicon | 正式支持         | 官网提供的 arm64 `.dmg`          |
| Windows                            | 暂无安装包       | 个人开发精力有限，暂无发布时间   |
| macOS Intel、Linux                 | 暂无正式公开发行 | 请勿把仓库构建目标当作可用安装包 |

打开官网提供的 DMG，按 Finder 显示的安装说明将应用放入“应用程序”目录后再启动。若系统提示签名、来源或版本异常，先停止安装并回到官网核对版本信息；不要为了继续安装而关闭系统安全机制。有关平台与构建边界，见[支持的平台](../../releases/supported-platforms.md)。

## 首次启动

应用启动后会先加载本地服务、项目、模型设置、草稿和对话记录。首次启动或新版本首次运行可能需要更长时间；如果启动页显示失败，可以先点“重试”。

首次启动时，先登录 Captain Who 账户并等待软件许可完成校验；未登录或许可不可用时不能启动新的 Agent 回合。具体操作见[账户与软件许可](account-and-license.md)。

账户和许可确认后，完成模型配置：

1. 点击左侧栏底部的个人资料区域，再选择“设置”。
2. 打开“配置”。
3. 填写模型默认使用的 API URL 和 API Token。
4. 新安装默认没有预置模型条目；进入“管理模型”新增服务实际提供的模型 ID，再启用它。
5. 返回应用，创建“新对话”，确认输入框下方能选到该模型。

模型名称出现在列表中并不代表接口已经可用。Captain Who 只有在发起真实请求时才能验证地址、Token、模型标识和服务端兼容性。

完整字段说明见[模型与服务商](../everyday-use/models-and-providers.md)。

## 可选配置

- 联网搜索：在“设置 → 配置”中填写 Tavily API Key，再开启“联网搜索”。
- 权限：在“设置 → 常规”中决定是否开放“完全权限”或“自定义权限”。第一次使用建议保留默认权限。
- 语言与通知：在“设置 → 常规”中选择界面语言，配置普通任务的通知条件，以及普通任务与 Automation 共用的提示音和内容预览。
- Skill：内置 Skill 可直接从任务输入框选择；第三方 Skill 在“设置 → 技能”中安装。
- MCP：本地 MCP 服务器在“设置 → MCP”中单独添加、授权和启用。

## 更新与卸载

正式签名的 macOS 发行版内置应用内自动更新机制。完整初始化后，只有在可访问的官方更新源提供新版本时，应用才会显示“下载更新”；由你主动点击后，下载、校验和准备完成，应用会重启并安装更新。它不会在你未开始下载时自动下载、静默替换或强制推送更新。下载前让正在运行的任务结束，并保存重要项目文件；完成重启后先确认模型连接和项目读取正常。更新源暂时不可用时，回到官网下载最新版 DMG 并按正常安装流程覆盖升级。

卸载应用不等于擦除全部本地数据。若要先清理界面可管理的内容，可以逐个移除项目，把剩余对话归档，再到“设置 → 已归档对话”执行永久删除。当前没有“一键清空全部应用数据”的入口，模型配置、凭据和其他应用数据可能继续保留；不要猜测并删除系统目录中的文件。
