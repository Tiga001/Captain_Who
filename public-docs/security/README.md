# 安全中心

MyCopilot 可以读取文件、运行命令、调用外部服务和操作受管浏览器。安全使用依赖应用边界，也依赖用户选择最小权限、审查扩展和保护本机账户。

## 文档

- [安全概览](security-overview.md)
- [数据与权限](data-and-permissions.md)
- [安全使用](safe-use.md)

这些页面只说明当前产品中可以核实、且用户能够据此采取行动的安全边界；它们不是安全认证、操作系统沙箱证明或漏洞响应政策。
