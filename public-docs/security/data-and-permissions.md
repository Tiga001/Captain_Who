# 数据与权限

Captain Who 是本地优先的桌面应用。要准确理解数据边界，需要区分本机桌面数据、Captain Who 的网站/账户服务数据，以及你主动使用的第三方服务数据。

## Captain Who 不接收的桌面任务数据

Captain Who 的账户与软件许可服务不会接收或同步以下桌面任务数据：

- 项目目录、工作区文件、附件和生成制品；
- 对话、消息、草稿、归档、搜索索引、上下文摘要和 Agent Run；
- Tool 调用参数与结果、审批记录、Automation 任务及其运行轨迹；
- 模型、搜索和图片生成密钥，MCP 调用内容，以及受管浏览器的 Cookie、历史和下载记录；
- 本机 Token 活动与本地用量估算。

这些数据主要保存在设备上的 Captain Who 应用数据目录，或直接发送给你选择的模型、搜索、图片、网站或 MCP 服务。登录、切换账号和许可校验不会上传或迁移本机对话、项目文件、模型设置或本机 Token 活动。

上述范围描述的是应用的常规数据流；如果你主动通过支持邮件、网站表单或其他渠道向项目方提交内容，对应提交内容会进入该渠道的处理范围。

当前桌面应用实现中没有内置的产品遥测或崩溃自动上报路径；这不影响你主动连接的第三方服务，也不代表第三方服务不会记录其自身请求。

## 网站、账户与许可服务处理的数据

使用网站账户、登录桌面应用或启动新的 Agent 回合时，Captain Who 的网站、账户与许可服务需要处理运行这些功能所必需的数据，包括：

- 账户身份信息，例如邮箱和账户标识；
- 你在网站个人资料中填写或设置的资料，例如显示名称、头像及其他个人资料字段；
- 登录、会话、账户状态与认证所需的信息；
- 软件许可校验的请求和结果，用于判断能否启动新的 Agent 回合；
- 服务运行和安全所必需的请求记录，例如请求时间、IP 地址、客户端信息、请求标识以及错误或安全事件记录。

这些数据不等同于桌面任务内容。账户服务不会因此获得你的项目、对话、文件、Tool 轨迹、模型密钥或 MCP 调用内容。网站账户资料和网站数据的处理、保留规则以官网的[隐私政策](https://captainwhoagent.com/legal/privacy)为准；使用网站和网站账户服务还应阅读[使用条款](https://captainwhoagent.com/legal/terms)。当前官网法律页面不替代桌面客户端专属法律说明，本页只记录可从产品实现核实的数据边界。

## 本机保存的数据

Captain Who 使用操作系统为应用分配的数据目录。当前主要包含：

- 项目、对话、消息、草稿、归档和搜索索引；
- Agent Run、Tool 轨迹、审批、上下文摘要、本机 Token 活动和用量估算；
- Automation 任务、Run、attention 和通知投递状态；
- 模型、搜索、Skill、MCP 和界面设置；
- 附件、已安装 Skill、生成图片、浏览/下载历史和受管浏览器数据；
- 凭据的不透明引用、配置状态；未签名 macOS 开发构建还可能包含私有凭据文件。
- 已登录账户的本机会话；在系统可用时，它使用 Electron 的安全存储加密。

模型 Token、Tavily Key 和图片生成 API Key 与普通配置分离。当前 SQLite 只保存不透明引用、状态和非秘密元数据；具备稳定签名身份的发行构建使用操作系统凭据存储，未签名 macOS 开发构建使用数据目录内权限收紧的私有文件。设置界面只能看到“未配置 / 已配置 / 不可用”等状态，不能读回已有密钥。不要把整个应用数据目录当作普通诊断附件。

当前版本创建的 SQLite 备份不包含当前模型/搜索密钥本身，但旧版本备份可能仍含明文凭据；只恢复 SQLite 也不会恢复操作系统凭据。删除设置或凭据不代表能从 SSD、系统备份或系统凭据存储中安全擦除所有副本。怀疑泄露时，应在相应服务商处撤销或轮换密钥。

## 可能发送给服务提供方的数据

| 功能                 | 接收方                           | 可能发送或处理的内容                                           |
| -------------------- | -------------------------------- | -------------------------------------------------------------- |
| 登录、个人资料与许可 | Captain Who 网站、账户与许可服务 | 账户、个人资料、认证/会话、许可校验及必要的服务与安全请求记录  |
| 模型对话             | 你配置的模型 Provider            | 当前任务说明、必要历史、读取的文件内容、Tool 定义和结果投影    |
| 联网搜索与网页读取   | Tavily                           | 搜索查询或目标 URL，以及服务所需请求信息                       |
| 图片生成             | 配置的图片 Provider              | Prompt、生成参数和可选参考图片                                 |
| 手动/自动浏览器      | 访问的网站                       | 标准网页请求、表单输入、上传内容、Cookie 与站点存储            |
| 外部 MCP             | 你安装并启用的 MCP Server        | Tool 名、调用参数及其运行所需数据；Server 可能继续访问其他服务 |
| Skill 安装           | GitHub 或授权本地来源            | 获取所选 Skill 包所需的仓库/文件请求                           |

模型、搜索、图片、网页和 MCP 请求由你的设备直接发往相应服务，而不是经 Captain Who 账户服务转发。它们各自的数据使用、保留、地域和安全规则由对应服务提供方决定；在发送前请确认你有权提交相关内容。

## 三种任务权限

### 默认权限

主要允许工作区内读写；命令和补丁等操作需要审批，命令按受保护模式执行。适合日常任务。

### 完全权限

允许更广泛的文件读写，并可自动批准命令和补丁，命令使用完全访问模式。只应在你信任任务、项目和输入来源时短时启用。

### 自定义权限

允许分别设置读取、写入、命令、FileChange 和符合条件的内置执行行为。命令仍保持受保护模式；内置自动批准不适用于 Installed/Workspace Skill。自定义并不等于操作系统沙箱。

在“设置 → 常规”中可以启用完全权限或自定义权限并调整细项。每个任务仍需选择实际使用的模式。

## Automation 权限

保存 Automation 时，当前权限会被冻结到任务配置和每次 Run。之后关闭 Full/Custom 模式会阻止相应新 Run，但修改 Custom 的细项不会自动收窄已经保存的旧任务。要降低权限，应编辑每个相关任务，或关闭整个权限模式以阻止未来启动。

暂停 Automation 只影响未来调度，不会停止活动 Run。后台需要审批时仍必须由用户对具体动作作出决定。

## 删除和清理

- 删除对话会删除其应用内消息和相关记录。
- 移除项目会删除 Captain Who 中该项目的本地对话与附件记录，但不会修改项目目录文件。
- “清除浏览数据”可按类别清理历史、Cookie/站点数据、缓存和下载记录；清除记录不保证删除磁盘上的下载文件。
- Automation 删除使用保留历史一致性的删除记录；当前没有面向用户的完整历史清理策略。
- 当前没有“一键删除全部本地数据”或正式数据导出向导。
- 删除本机项目或对话不会删除网站账户或个人资料；账户数据相关事项以[隐私政策](https://captainwhoagent.com/legal/privacy)中的说明为准。

删除不能撤回已经发送到 Provider、MCP Server、网页或其他第三方的数据；相关保留规则由第三方决定。
