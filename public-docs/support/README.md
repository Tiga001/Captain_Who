遇到问题时，先停止可能产生重复副作用的操作，再保留首次错误和必要上下文。不要把 Token、Cookie、完整对话、私有文件或数据库上传到公开渠道。

## 联系项目方

完成自助排查后，如仍需联系项目方，请将脱敏后的最小复现材料发送至 [sh_jiao@zju.edu.cn](mailto:sh_jiao@zju.edu.cn)。请说明 Captain Who 版本、操作系统与架构、发生时间/时区、最短复现步骤和首次错误；准备方式见[诊断信息与日志](diagnostics-and-logs.md)。

该邮箱不是工单系统、加密文件传输渠道，也没有在本文档中承诺响应时限或服务等级。涉及凭据、可利用细节或他人数据的问题不要公开发布，也不要在邮件中附上完整数据库、完整对话或未经脱敏的日志。
