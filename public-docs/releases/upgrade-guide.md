# 升级指南

本指南适用于当前正式支持的 macOS 12+ Apple Silicon（arm64）发行版。先将 `Captain Who.app` 拖入“应用程序（Applications）”等本机位置并从那里启动；直接从挂载的 DMG 或 macOS App Translocation 路径运行时，应用内更新不会启用。正式签名的 Captain Who 内置由用户发起的应用内自动更新机制，官方公开更新清单现已可用：完整初始化后，只有在可访问的官方更新源提供新版本时，应用才会展示下载选项；由你选择开始下载。下载、完整性校验和原生准备完成后，应用会关闭并重新启动以安装更新。更新不会在你开始下载前自动下载、静默替换或强制执行，也不会自动降级。

如果你希望自行控制安装时机、应用内检查失败，或需要重新获取安装文件，也可以从 [Captain Who 官网](https://captainwhoagent.com/) 下载官方 DMG 并手动替换应用。

## 升级前

1. 阅读对应[发行说明](release-notes/README.md)，确认新版本适用于你的设备和工作流。
2. 等待正在运行的 Agent、命令、MCP 调用和 Automation Run 结束，或先安全停止它们。
3. 备份重要项目文件。项目目录由你自行管理，Captain Who 不会替你备份它们。
4. 如需保留本地对话与设置的额外恢复手段，备份完整的 Captain Who 应用数据目录；不要只复制单个数据库文件。

应用历史与配置主要保存在本机。模型、搜索和图片生成凭据与 SQLite 配置分开保存；仅复制数据库并不能保证恢复这些凭据。任何包含历史数据或凭据的备份都应按敏感数据妥善保管。

## 使用应用内更新

1. 正常启动 Captain Who，等待应用完成初始化和更新检查。
2. 发现可用版本时，先阅读版本号和发行说明；确认后选择下载。
3. 保持网络连接，等待下载和准备完成。下载完成不代表安装已经发生。
4. 下载和准备完成后，应用会关闭并重新启动以安装新版本。
5. 重新打开后，确认应用“关于”页面显示预期版本，再用低风险任务验证模型连接和项目读取。

你可以不开始下载；这会保留当前版本。若官方更新源暂时不可访问，也可改用官网 DMG 手动升级。应用不会在你开始下载前自动下载或无提示替换自身，也不会将已安装版本自动回退为旧版本。

## 通过官网 DMG 手动升级

1. 从官网下载安装包。当前正式包为 `Captain-Who-1.0.5-arm64.dmg`；后续版本应以对应发行说明中的文件名为准。
2. 按[下载与验证](download-and-verification.md)核对 SHA-256，并确认 macOS 没有显示来源或签名警告。
3. 完全退出 Captain Who，双击打开 DMG，将 `Captain Who.app` 拖入“应用程序（Applications）”文件夹；系统要求替换旧应用时，确认替换。
4. 从“应用程序”启动 Captain Who，确认项目、对话和设置可以正常加载。
5. 先用低风险任务验证模型连接，再按需检查 Skill、MCP、浏览器和 Scheduled Automation。

不要使用未签名开发构建、目录包，或来自 Intel Mac、Windows、Linux 的文件覆盖当前正式安装。

## 升级后需要重新确认的事项

- 如果更换了设备、macOS 用户账户或应用签名身份，模型、搜索或图片生成凭据可能需要重新输入。
- 启动新的 Agent 任务需要有效的账户登录和桌面许可状态；如界面提示状态异常，先完成登录或检查账户状态。
- 已写入的文件、已发送的网络请求和已经触发的第三方操作不能因升级而自动回滚。

## 如果升级失败

- 保留首次错误信息，不要反复启动可能产生副作用的任务。
- 不要手工编辑 SQLite schema、删除数据库或复制未知来源的应用内部文件来绕过错误。
- 如果旧版本无法打开新版本写入的数据，不要强制降级；当前没有公开的跨版本数据库回滚承诺。
- 保留升级前的完整备份，并按[诊断信息与日志](../support/diagnostics-and-logs.md)整理不含 Token、Cookie、完整对话或私有文件的复现资料。
