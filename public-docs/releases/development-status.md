# 当前开发进展

截至 2026-11-05，本次核验的功能基线为 `5dc40325`，与正式发行标签 `v1.0.7` 一致，没有另列尚未发布的功能。此前本页记录的 Kimi K3.1、智谱 GLM-5.3、下一条消息预测、组织邮件协作与 Markdown 模板、长会话和用量改进已随 `1.0.7` 发布，详见 [1.0.7 发行说明](release-notes/1-0-7.md)。

仍使用 `1.0.6` 的用户需要升级才能使用这些新增功能。官网文档更新、仓库新提交和应用内更新是不同流程；不要仅凭文档内容判断本机安装包的能力。后续开发进展将在本页按新的核验基线记录，不回写旧版发行范围。

## 仍需验证的部分

本地存储、并发调度和运行记录已有改进，但不能据此承诺固定并发数量、响应时间或运行记录绝不丢失。最近一次综合性能验收仍有发送延迟和长时间负载失败项，后续正确性修复不替代重新测量，正式发布也不意味着所有性能目标均已达成。

正式平台仍限 macOS 12+ Apple Silicon，未新增 Windows、Intel Mac 或 Linux 安装包。应用内更新源由官网发布渠道独立管理，GitHub 已发布不代表所有已安装版本都能立即收到更新提示。

后续开发构建不要直接覆盖日常数据。请参考[升级指南](upgrade-guide.md)、[平台与构建状态](supported-platforms.md)和[已知问题](../support/known-issues.md)。
