# 版本与发布

本区域只记录已经有公开证据的发布事实。构建配置、源码中的版本号或开发测试通过，都不等于某个平台安装包已经正式发布。

## 文档

- [平台与构建状态](supported-platforms.md)
- [升级指南](upgrade-guide.md)

## 当前发布状态

当前应用构建元数据为 `1.0.0`，但仓库没有与之对应的公开 Release Notes、自动更新通道或可验证的公共下载地址。因此，不能仅凭这个版本号判断某个安装包已经正式发布、经过目标平台验收或仍在支持期内。

如果你从某个组织或开发者处获得安装包，应由该分发方同时说明来源、适用平台与架构、签名或校验方式及已知限制。本区域记录的源码构建能力不能替安装包提供来源证明；第三方重打包也应视为独立分发。
