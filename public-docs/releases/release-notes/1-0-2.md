# Captain Who 1.0.2 发行说明

发布日期：2026-09-14
正式支持：macOS 12 或更高版本、Apple Silicon（arm64）

Captain Who 1.0.2 是当前正式发布版本。对应安装包为 `Captain-Who-1.0.2-arm64.dmg`，已使用 Developer ID 签名、通过 Apple 公证，并已装订公证凭据。下载前请阅读[下载与验证](../download-and-verification.md)。

## 主要更新

### 正式发行与账户访问

- 提供 macOS Apple Silicon 的正式 DMG 发行包。
- 新建 Agent 任务需要有效账户登录与桌面许可状态，以便应用确认当前访问资格。
- 新增本地 Token 活动统计，帮助你查看设备上的模型用量记录。

### 项目与任务工作流

- 一个项目现在可使用一个主文件夹和多个附加文件夹；每次 Agent Run 会固定其启动时的工作区范围。
- 文件、终端和 Git Review 可在项目的文件夹之间切换；Git Review 支持工作区、提交和分支目标。
- 支持手动压缩对话上下文，以及从既有对话创建分支，便于继续探索不同思路。
- Agent 可以在需要关键输入时向你提问，并在你回答后继续任务。

### 模型与使用体验

- Moonshot 作为一类可配置的模型 Provider 加入。
- 设置、项目和聊天界面进行了可读性与空间利用改进；新增帮助与文档入口。
- macOS 终端以登录 shell 启动，改善从 Finder 启动应用时继承本机 PATH 的体验。

### 更新、稳定性与安全性

- 正式签名的 macOS Apple Silicon 版内置应用内自动更新机制：完整初始化后，只有在可访问的官方更新源提供新版本时才会显示下载选项；由你选择开始下载，随后在校验和准备完成后自动重启安装。它不会在你开始下载前自动下载、静默强制更新或自动降级。
- 加强任务、工作区和浏览器目标在运行期间的状态固定，减少界面切换或设置变更影响正在进行的任务。
- 加强 macOS 发行包的安全配置和更新流程准备阶段的状态处理。

## 升级注意事项

- 官方更新源可访问时，启动应用后可使用应用内更新；你也可以手动下载新 DMG 并替换应用。
- 升级前应等待或停止正在运行的 Agent、命令、MCP 调用和 Automation Run，并备份重要项目文件。
- 当前正式范围只包括 macOS Apple Silicon。不要将此安装包用于 Intel Mac、Windows 或 Linux。

完整步骤见[升级指南](../upgrade-guide.md)，平台范围见[平台与构建状态](../supported-platforms.md)。

## 已知边界

- Windows、Intel Mac 和 Linux 尚未发布正式安装包。
- 本版本不提供自动回滚服务；如果升级后遇到问题，不要删除本地数据或手工修改数据库来强制降级。
- 模型 Provider、联网搜索、MCP Server 和浏览器操作仍受你的配置、权限和第三方服务状态影响。请在执行有副作用的操作前审查审批内容。
