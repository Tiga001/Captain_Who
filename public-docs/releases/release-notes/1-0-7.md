# Captain Who 1.0.7 发行说明

**发布日期：2026-11-05。** [官方 GitHub Release](https://github.com/Tiga001/Captain_Who/releases/tag/v1.0.7) 对应标签 `v1.0.7`（`5dc40325`），适用于 macOS 12 及以上的 Apple Silicon 设备。

## 相较 1.0.6 的主要更新

### Kimi 与智谱模型接入

新增 Kimi K3.1 Pro 及其高速版，以及智谱 GLM-5.3、Flash、FlashX 和 FlashX-Legal 专用配置。选择专用厂商后，可从已适配型号中选择，使用固定官方 API 地址和对应推理设置。

智谱专用配置使用国内标准 API Key，不是 Coding Plan 套餐或海外 Z.AI 接入；旗舰型号仅接收文本，Flash 系列可接收图片。显示名称、上下文窗口和估算价格仍由用户填写，已有配置不会自动迁移。步骤见[连接模型 Provider](../../integrations/model-provider-integration.md)。

### 可选的下一条消息预测

在“设置 → 常规 → 输入框”开启“预测下一条用户消息”，默认关闭。回复结束且输入框为空时，可能出现下一句建议；按 `Tab` 只会填入草稿，不会自动发送。

预测可能将已有对话上下文发送给当前模型服务商，即使不采用建议也可能产生 Token 用量和费用；预测本身不调用工具。操作与数据边界见[任务与对话](../../user/everyday-use/tasks-and-conversations.md#预测下一条用户消息)和[数据与权限](../../security/data-and-permissions.md)。

### 组织与邮件协作

新增组织协作：为成员分配职责、模型和权限，通过持久邮件分工，在看板查看成员状态。成员可以归入部门，并按职级和管理范围进行组织内管理。

组织模板可以导出为 Markdown，再导入为独立新模板；导入后需重新选择成员模型，不会自动启动成员。分享前仍需检查自己写入的说明是否含敏感信息。详见[组织指南](../../user/capabilities/organizations.md)。

### 长会话与工具记录

长对话按需加载历史并保留阅读位置，连续读取、搜索、编辑和命令活动可分组展示；读取文件的记录可以打开当前文件预览。模型历史与界面展示分别处理，减少展示变化对历史复用的影响，但不保证模型服务商的缓存命中率。详见[上下文与历史](../../user/everyday-use/context-and-history.md)。

### 内置本地账户

支持不依赖官网注册或在线许可的内置本地账户。它只提供本机应用使用资格，不提供云端身份、模型额度或独立的数据空间；模型服务仍需自行配置。登录方式见[账户与软件许可](../../user/getting-started/account-and-license.md)。

### Git 审阅修正

修正行数统计缺失或超限时，部分文件被审阅列表遗漏的问题，并区分二进制文件与无法完整统计的文件。活动中的审阅面板会在相关 Agent 文件写入或命令结束后刷新，减少手动刷新。此处修正的是审阅展示，不是替用户备份或还原磁盘文件。详见[文件与 Git](../../user/everyday-use/files-and-git.md#用审阅检查-git-变更)。

- 先结束或安全停止任务，完全退出应用后备份重要项目和本地数据；本版包含数据库调整，不应假设升级后的数据可由旧版打开。
- 应用内自动更新由官网发布渠道独立管理。GitHub 已发布 `1.0.7` 不表示所有已安装版本都会立即收到更新；也可以核验官方 DMG 后手动升级。具体步骤见[升级指南](../upgrade-guide.md)。
- 当前仍无 Windows、Intel Mac 或 Linux 的正式安装包。模型账户权限、外部服务可用性和费用由对应服务商决定。
