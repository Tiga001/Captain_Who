# Captain Who 1.0.5 发行说明

发布日期：2026-09-17  
正式支持：macOS 12 或更高版本、Apple Silicon（arm64）

Captain Who 1.0.5 是当前正式发布版本。对应安装包为 `Captain-Who-1.0.5-arm64.dmg`，已使用 Developer ID 签名、通过 Apple 公证，并已装订（stapled）公证凭据。下载前请阅读[下载与验证](../download-and-verification.md)。

## 主要更新

### 项目指引与 Multi-Agent 协作

- 支持在项目中使用 `AGENTS.md` 提供项目级工作说明，帮助 Agent 在开始任务前了解适用的工作约定、验证方式和注意事项。具体写法见[项目工作说明（AGENTS.md）](../../user/everyday-use/agents-md.md)。
- 在启用 Multi-Agent 且任务存在可独立完成的部分时，根 Agent 会主动评估并优先并行委派子任务，以便汇总结果。并非每个任务都会拆分；你仍可在任务中限制协作范围、指定不委派，或要求先征求意见。

### 模型、模板与自动化

- 统一模型可用性判断。对话中的模型选择、任务模板和 Scheduled Automation 现在使用一致的可用性结果。
- 只有已启用、连接配置完整且本机凭据当前可用的模型，才会作为可执行选项出现。这反映本机配置状态，不代表第三方服务一定可用；实际调用仍取决于网络、账户与服务商状态。

### 发布与更新

- 提供 macOS Apple Silicon 的正式 DMG 发行包，并保持 Developer ID 签名、Apple 公证和公证凭据装订。
- 官方公开更新清单已上线。已安装到本机位置的应用可检查新版本；由你选择开始下载，完成下载、校验和准备后，应用会自动重启安装。开始下载前不会静默下载或强制替换当前版本，也不会自动降级。

## 升级注意事项

- 当前正式范围只包括 macOS Apple Silicon。不要将此安装包用于 Intel Mac、Windows 或 Linux。
- 升级前应等待或停止正在运行的 Agent、命令、MCP 调用和 Automation Run，并备份重要项目文件。
- 应用内更新不可用时，可从官网重新下载 DMG 并手动替换应用；完整步骤见[升级指南](../upgrade-guide.md)。

## 已知边界

- `AGENTS.md` 是项目内的工作说明，不会替代你对文件写入、命令、联网或其他有副作用操作的审查。
- Multi-Agent 是否拆分取决于任务的独立性和运行条件；并行任务可能带来额外的模型调用与第三方服务用量。
- 模型 Provider、联网搜索、MCP Server 和浏览器操作仍受你的配置、权限和第三方服务状态影响。请在执行有副作用的操作前审查审批内容。
