# Captain Who 1.0.6 发行说明

**发布日期：2026-09-23。** [项目官方 GitHub Release](https://github.com/Tiga001/Captain_Who/releases/tag/v1.0.6) 对应标签 `v1.0.6`（`1278cf10`），提供 macOS 12 及以上 Apple Silicon 设备的 DMG。

## 这一版可以做什么

- 在输入框输入 `@` 搜索工作区文件，或通过 `+` 和空 `@` 菜单选择附件、文件夹与 Skill。
- 可以只发送附件或文件夹引用，不必另外补一句文字。文件夹引用告诉模型该目录的位置，不会把整个文件夹的内容预先读入对话。
- 排队消息和运行中追加的引导可以复用已导入的附件，不必为了再次提交而重复选择文件。

这些行为依据发行标签核对。11 月 3 日加入主分支的「预测下一条用户消息」**不在这个安装包中**；找不到该开关不需要重新安装。后续功能见[当前开发进展](../development-status.md)。

## 下载与升级

可以从 [Captain Who 官网](https://captainwhoagent.com/) 开始，或直接在上述 GitHub Release 的 **Assets** 中选择 `Captain-Who-1.0.6-arm64.dmg`，不要下载 Source code。文件大小和 SHA-256 见[下载与验证](../download-and-verification.md)。

GitHub 上有 DMG，不代表应用内更新源已提供同一版本。如果没有更新提示，可以核验 DMG 后手动升级，步骤见[升级指南](../upgrade-guide.md)。Windows、Intel Mac 和 Linux 没有此版本的官方安装包。
