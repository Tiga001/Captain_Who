# Captain Who website wordmarks

All logo files have transparent backgrounds and fixed colors. The SVG files are self-contained and embed the original raster alpha mask so the word shape remains pixel-identical to the application.

## Primary light/dark pair

- `captain-who-wordmark-classic-light.svg` / `.png`: for light surfaces such as `#F7F7F5` or white.
- `captain-who-wordmark-classic-dark.svg` / `.png`: for dark surfaces such as `#171717`.

## Current screenshot theme

- `captain-who-wordmark-crab-light.svg` / `.png`: same light wordmark colors with the Crab theme accent `#A64B31`, for surfaces such as `#ECE8E0`.

Each full PNG is 2035 × 385. Each `-web.png` is 814 × 154 for convenient 2× display at 407 × 77 CSS pixels. Prefer SVG on the website when possible.

The three accent marks are fixed to the selected theme color and do not depend on CSS variables.
`Captain` is fixed charcoal `#2B3540` in light variants and the original white `#FEFEFE` in the dark variant; only `Who` uses the brand gradient.
